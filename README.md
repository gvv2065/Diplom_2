## Функциональность

### Тестируемые модули

- **Создание пользователя** - регистрация новых пользователей, валидация обязательных полей, проверка дублирования
- **Вход пользователя** - аутентификация и получение токена доступа
- **Создание заказа** - создание заказов с авторизацией и без авторизации

### Примеры тест-кейсов

**Пользователь:**
- ✅ Успешное создание пользователя
- ✅ Попытка создания существующего пользователя (возврат 403)
- ✅ Создание пользователя с отсутствующими обязательными полями (email, password, name)
- ✅ Успешный вход под существующим пользователем
- ✅ Попытка входа с неверным логином и паролем


**Заказ:**
- ✅ Создание заказа с авторизацией
- ✅ Создание заказа без авторизации
- ✅ Создание заказа с ингредиентами
- ✅ Создание заказа без ингредиентов
- ✅ Создание заказа с неверным хешем ингрдиентов

## Требования

- Python 3.11+
- pip

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd Diplom_2
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Зависимости

- **pytest** (9.0.1) - фреймворк для написания и запуска тестов
- **requests** - библиотека для HTTP запросов
- **allure-pytest** - интеграция Allure для генерации отчетов
- **faker** - генерация случайных тестовых данных


## Запуск тестов

### Запустить все тесты
```bash
pytest
```

### Запустить тесты с подробным выводом
```bash
pytest -v
```

### Запустить конкретный тест-файл
```bash
pytest tests/test_create_user.py
```

### Запустить конкретный тест
```bash
pytest tests/test_create_user.py::TestCreateUser::test_create_user
```

### Генерация Allure отчета
```bash
pytest tests --alluredir=allure_results
allure serve allure_results
```

После запуска тестов с Allure, отчет можно просмотреть командой:
```bash
allure serve allure_results
```
